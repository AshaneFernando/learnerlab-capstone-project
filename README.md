# LearnLab

A lightweight Learning Management System — course authoring, catalog, enrolment, sequential lessons, deterministic quiz grading, progress tracking, an instructor workbench and an admin console.

AI-Native Engineer capstone **BC-AINE-011**. Every line of production code is generated by Claude Code agents through the Claude Harness Engine; the engineer writes specifications, configures agents and guardrails, and reviews pull requests.

All changes reach `main` through pull requests merged with a merge commit (`--no-ff`). A quick-start guide is added once the application is scaffolded.
